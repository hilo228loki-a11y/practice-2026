# Кейс 3. Генерация продуктовых гипотез (Синаптик)

- `Кейс3_Синаптик_гипотезы.docx` — результат: пять гипотез с данными, методом, цифрами, выводами и ограничениями.
- `scripts/case3_logs.py` — разбор клиентских логов (`logs.zip`) → `logs_results.md`, `logs_features.csv`.
- `scripts/case3_analysis.py` — анализ дампа БД (SQLite) → `case3_results.md`.
- `results/` — агрегированные результаты запусков (без персональных данных).

Запуск (папка `db` — выгрузка с Яндекс.Диска; сначала логи, потом БД, так как БД-скрипт использует `logs_features.csv`):

    python scripts/case3_logs.py db/logs.zip
    python scripts/case3_analysis.py db

Скрипты пишут результаты в текущую папку. Файлы `logs_features.csv` (номера пользователей) и `case3.sqlite` (гигабайты) в репозиторий не добавлять.
