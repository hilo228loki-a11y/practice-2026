# Кейс 2. Восстановление процесса по журналу событий (ELMA365)

- `Otchet_Case_2_Final.docx` — отчёт со схемой процесса.
- `variants.csv` — таблица полных вариантов: `Variant,Route,NumberOfCases,Share`.
- `student_transitions.csv` — переходы между активностями: `SourceActivity,TargetActivity`.
- `generate_tables.py` — код, строящий обе таблицы по журналу.

Запуск: положить журнал `students.csv` рядом со скриптом и выполнить `python generate_tables.py`.
